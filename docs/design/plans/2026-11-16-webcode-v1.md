# Webcode v1 Implementation Plan


**Goal:** Build Webcode v1: a dark, Google Docs-style web app where you open a JS/TS project, share a link, edit files together in real time, and install/run/test it inside each visitor's browser.

**Architecture:** A pnpm monorepo. `apps/server` is one Node process serving the built SPA, a Hono HTTP API, and a Hocuspocus (Yjs) WebSocket endpoint on the same origin, backed by Neon Postgres. `apps/web` is a React + Vite SPA using Monaco + y-monaco for editing, `@webcontainer/api` to run code in the browser, and xterm.js for terminals. `packages/shared` holds pure logic both sides use (path rules, limits, access, the Yjs project-doc schema).

**Tech Stack:** Node 22, pnpm 9, TypeScript 5 (strict), Vitest, Playwright; server: Hono + `@hono/node-server`, `@hocuspocus/server` + `@hocuspocus/extension-database`, `ws`, `postgres` (porsager), `tar-stream`; web: React 19, react-router 7, `monaco-editor`, `y-monaco`, `yjs`, `@hocuspocus/provider`, `@webcontainer/api`, `@xterm/xterm` + `@xterm/addon-fit`, `fflate`; hosting: Fly.io.

**Spec:** `docs/design/specs/2026-11-16-webcode-v1-design.md` (mockups: `docs/design/specs/assets/2026-11-16-webcode-mockups.html`, workspace = layout A). Read both before starting any task.

## Global Constraints

- Every HTML/JS/CSS/asset response sets `Cross-Origin-Opener-Policy: same-origin` and `Cross-Origin-Embedder-Policy: require-corp`. No CDN assets: Monaco, fonts, icons are bundled. GitHub avatars only via `/api/avatar/:userId`.
- GitHub OAuth uses a full-page redirect (never a popup), scope `read:user`.
- Session cookie: `HttpOnly`, `Secure` (except on `localhost`), `SameSite=Lax`, 30-day expiry renewed on use. Guest cookie is HMAC-signed.
- Project IDs: ≥128 bits of randomness, base64url.
- Limits (exact): ≤ 2,000 files/project; ≤ 1 MB (1,000,000 bytes) per file; ≤ 10 MB (10,000,000 bytes) stored Yjs state per project; ≤ 20 projects/user; ≤ 10 creates/imports/copies per user per hour; site-wide stored size 400 MB (400,000,000 bytes) → refuse creates with "Webcode is full right now"; ≤ 20 simultaneous connections/project; demo: 1 live copy/guest, ≤ 5 new demo copies/IP/hour, ≤ 300 live demo copies ("The demo is busy, try again in a few minutes"), deleted after 24 h without activity.
- Never synced to Yjs: `node_modules/`, `.git/`, `dist/`, `build/`, `coverage/`, `.next/`, `.cache/`, `.vite/`, files > 1 MB, binary files. Lockfiles (`package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`) sync with whole-content replace.
- Palette: page `#1b1b1d`, surfaces `#26272a` / `#2f3034`, borders `#3a3b3f`, text `#e3e3e3`, muted `#a6a8ab`, accent `#8ab4f8`, ink on accent `#0b2a5c`, success `#81c995`. No Google names, logos, or icons anywhere. No Agents menu, no comments icon.
- Copy strings fixed by the spec are used verbatim (sync status, banners, errors) — see the tasks that own them.
- Commits: authored by RealCloudyPanda.
- Test-only login route (`POST /auth/test-login`) exists only when `E2E_TEST_LOGIN=1` **and** `NODE_ENV !== 'production'`.

## Review Focus

1. **Sync loops under concurrent activity:** two editors typing while one runs `npm install` must converge to identical files with no endless write/watch loop. → test in Task 15 (`converges without echo loops when two engines share a doc`).
2. **Hostile paths from imports and clients:** `../x`, `/etc/passwd`, `a\\b`, `a//b`, `.`/empty segments, tarball symlinks — rejected or normalized, never written outside the project. → tests in Task 2 (`normalizePath`) and Task 9 (`skips symlinks and traversal entries`).
3. **Access revoked mid-session:** switching link access to Restricted disconnects connected guests/users immediately; Viewer makes them read-only. → test in Task 10 (`reevaluateAccess closes or downgrades live connections`).
4. **Forged guest cookie:** a tampered or unsigned guest cookie is treated as anonymous, never as the owning guest. → test in Task 6 (`rejects a tampered guest cookie`).
5. **Non-UTF-8 and CRLF content:** CRLF files round-trip byte-exact through Yjs ↔ container; invalid UTF-8 is treated as binary and skipped. → tests in Task 2 (`isProbablyBinary`) and Task 15 (`preserves CRLF`).
